🌿 **IronGrove Translator 0.8.2 PORTABLE**
**Veřejný test pro komunitu Iron Grove / WoW Forever**

Nerozumíš zprávě v angličtině nebo potřebuješ napsat odpověď? IronGrove Translator pomůže s překladem **EN ↔ CZ přímo na tvém počítači**.

⚔️ **Co umí**
• **Offline překlad** — bez internetu, registrace, API klíčů a poplatků.
• **Dva samostatné panely** — příchozí zprávy EN → CZ a tvoje odpovědi CZ → EN.
• **Automatický překlad schránky** — po zapnutí přeloží nově zkopírovaný text.
• **WoW addon** — usnadňuje kopírování zpráv; aplikace rozpozná autora a kanál.
• **Overlay** — překlad v samostatném okně s nastavením velikosti, písma, průhlednosti a pozice.
• **Historie překladů** během aktuálního spuštění.
• **Herní fráze a rychlé odpovědi** pro běžnou komunikaci.
• **Vlastní opravy překladů**, které se uloží pro příště.
• **Fantasy vzhled Iron Grove** a automatické ukládání nastavení.

📦 **Jak začít**
1. Stáhni a **rozbal celý přiložený ZIP**.
2. Složku `Addon\IronGroveTranslator` zkopíruj do `Interface\AddOns` svého WoW klienta. Starý addon `EngetsuTranslator` vypni a hru restartuj.
3. Spusť `IronGroveTranslator.exe`. **Python ani další programy neinstaluješ.**
4. Ve hře otevři kopírování zprávy přes addon a stiskni **Ctrl+C**. Se zapnutým sledováním schránky se text přeloží.
5. Odpověď napiš česky v pravém panelu, přelož ji a ručně vlož do hry přes **Ctrl+V**.

⚠️ **Co je dobré vědět**
Aplikace sama nečte celý herní chat ani neposílá zprávy za tebe. Překlad následuje po zkopírování textu; odpověď vložíš a odešleš ručně.

Sledování schránky zachytává text ze všech aplikací, nejen z WoW. **Překlad probíhá lokálně; text se neposílá překladové službě.**

Jde o komunitní testovací verzi. Překlady mohou chybovat, hlavně u slangu a herních názvů. Funkčnost v různých sestavách WoW Forever a na dalších počítačích potřebujeme ověřit.

🐛 **Našel jsi chybu?**
Pošli verzi Windows a WoW klienta, popis problému a postup zopakování. U chybného překladu přidej původní větu a očekávaný význam — bez soukromých údajů.
